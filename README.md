# RPG Revolution

Servidor RPG de mundo aberto para Minecraft Java 26.3, desenvolvido com Skript puro (sem addons de Skript). ViaVersion será usado apenas para compatibilidade de clientes; ele não altera a versão-base do servidor.

> Estado: fundação inicial em desenvolvimento. Não instalar em produção antes da validação em um servidor Paper 26.3 com a versão compatível do Skript.
